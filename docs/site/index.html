Self-hosting

Yours in three commands.

Run the server on any box you control — a spare laptop, a home server, a Raspberry Pi — and reach it privately over Tailscale or behind Caddy. First run walks you through setup.

1

Start the server

A single Rust binary. Data lands in an encrypted directory you own.

2

Create your account

Your database key is wrapped by your password and a one-time recovery key — the server never stores it in the clear.

3

Import & connect

Drop in a CSV or link SimpleFIN, add your LLM key in Settings, and the copilot comes online — or skip it and stay fully offline.

~/finsight — zsh
# run the self-hosted server (data dir is yours)
$ cargo run -p finsight-server
INFO finsight-server listening on http://localhost:8674

# ...or with Docker, reachable over your tailnet
$ docker run -v ./data:/data -p 8674:8674 finsight
✓ first-run setup ready · open the URL to create your account

# it stays put — no telemetry, no outbound calls
$ curl localhost:8674/api/health
{"status":"ok"}
Local-first by construction

Your data has nowhere to leak, because it never leaves.

There is no FinSight cloud to breach. Each user gets their own SQLCipher database, wrapped by a key only your password (or recovery key) can open. Sessions live on the box you run.

  • Per-user SQLCipher encryptionOne encrypted database each, keyed by Argon2id.
  • Bring your own model — or nonePoint the copilot at a local Ollama and disconnect from the internet entirely.
  • Encrypted offline cacheThe installed PWA keeps a seven-day, AES-GCM-encrypted local cache.
