# Pure Self-Hosted + OpenAPI (Immich-inspired) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Delete the Tauri thin shell and replace `tauri-specta` bindings with a standard OpenAPI contract, keeping FinSight a single Docker container (UI baked in) with a split-ready seam — PWA via Tailscale is the primary client.

**Architecture:** `finsight-api` stays the transport-agnostic source of truth; `utoipa` annotates its handlers/DTOs and emits `openapi.json` at `/api/openapi.json`; a generated `openapi-typescript` client replaces `ui/src/api/httpBackend.ts` `__TAURI_INTERNALS__` shim; `finsight-server` keeps Axum static serving + `dispatch.rs` `rpc_routes!` but derives parity from the schema; `src-tauri/` + `desktop.yml` + `isTauriRuntime()` branches removed.

**Tech Stack:** Rust 1.78, `utoipa 4.x + schemars`, `openapi-typescript 7.x`, Axum, Vite 5, Docker multi-stage (node:20 → rust:1-bookworm → debian:bookworm-slim), Vitest, `cargo test`

## Global Constraints

- `rust-version = "1.78"` (`Cargo.toml:40`)
- `finsight-api` must have no `tauri` dep (`cargo tree -p finsight-api -i tauri` must be empty) — `crates/finsight-api/src/lib.rs:1`
- `AgentResponseBlock` Zod parity test stays green (`ui/src/components/copilot/agUi/artifacts.ts` ↔ `finsight-api/src/commands/agent.rs`)

// ui/src/api/client.ts
import createClient from "openapi-fetch";
import type { paths } from "./openapi";
const raw = createClient<paths>({ baseUrl: "/api/rpc" });
async function wrap<T>(p: Promise<{data?:T, error?:AppError}>) {
  const { data, error, response } = await p as any;
  if (!response.ok) {
    if (response.status===401 && (error as any)?.code==="auth.required") window.dispatchEvent(new CustomEvent("finsight:auth-required"));
    return { status:"error", error } as const;
  }
  return { status:"ok", data } as const;
}
export const api = { listAccounts: () => wrap(raw.POST("/list_accounts", {} as any)), /* ... per cmd */ };
// re-export types from openapi.ts for hooks
