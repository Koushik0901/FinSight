# Financial Journey

Seven milestones from stability to freedom — tracked against your ledger, with Copilot entry points at each stage.

| # | Milestone | Threshold (approx.) |
|---|---|---|
| 1 | Stability | Bills paid, income tracked, categories set |
| 2 | Emergency buffer | 1 month of expenses saved |
| 3 | Emergency fund | 3–6 months saved |
| 4 | Debt free | Non-mortgage debt cleared (snowball) |
| 5 | On track | Savings rate ≥10% sustained; allocation healthy |
| 6 | Compounding | Goals funded; 10/20/30-year projection credible |
| 7 | Freedom | Investments + cash cover years of expenses; Behaviour > math is the focus |

## How progress is computed

Journey reads the same `wellness_context` and goal/budget state as every other screen. A milestone unlocks when its thresholds are met against actual ledger data — the Copilot will not mark it complete on promises.

## Using Journey

- Click a milestone to open the Copilot with a grounded prompt for that stage.
- The progress reveal animates briefly and respects `prefers-reduced-motion`.
- “More” holds secondary detail so primary milestones stay scannable.

Journey is a map, not a scoreboard. The underlying math is exposed in the metric inspector whenever you want to check it.
