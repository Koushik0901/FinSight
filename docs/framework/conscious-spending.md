# Conscious Spending

> Tag every dollar as a Need, Want, Saving, or Investment — then look at the allocation. — *Sethi*

## Spending types

Each category in FinSight carries a `spending_type`:

- **Need** — housing, utilities, groceries
- **Want** — dining, shopping, travel
- **Saving** — emergency fund, sinking funds
- **Investment** — retirement, brokerage, education

Set it per category in **Categories**. The Budget allocation donut and `wellness_context` both read it.

## Why it matters

When every dollar has a type, drift becomes visible: wants quietly eating wants is a pattern, not a feeling. FinSight flags when wants exceed needs or when saving falls below wants without comment.

## Using it

- **Budget** — the donut updates live as you change envelopes. If Saving + Investment < 10%, the screen suggests a shift.
- **Categories** — review the type quarterly; moving “Dining” from Want to Need changes the Copilot’s warnings and the wellness score.
- **Copilot** — “How is my allocation this month?” returns the donut figures with the same source as Budget.

Conscious spending is not austerity. It is intentionality — the same income, fewer regrets.
