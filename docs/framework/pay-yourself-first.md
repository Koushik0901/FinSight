# Pay Yourself First

> Save at least 10% before anything else. Treat it as the first bill you pay. — *Babylon* / Ramsey

## What FinSight does

- **Savings rate gauge** on Today: `(income − expenses) / income` for the month. Green at ≥10%.
- **Copilot priority #1.** Every system prompt opens with “Pay Yourself First” as the first financial principle. When savings rate is below 10%, the next-action nudge and anomaly callouts point there before anything else.
- **Budget cue.** The allocation donut and the “To Budget” header surface when Saving + Investment fall below the threshold.

## How to use it

1. On **Budget**, ensure the Saving envelope is funded before allocating wants.
2. When imports pull a new month’s income, move money to **Goals → Emergency fund** — quick-fill computes the shortfall.
3. Ask the Copilot: “Am I paying myself first this month?” — it cites the rate, the inputs, and the shortfall in dollars.

The 10% is a floor, not a ceiling. Raise it once the emergency buffer is solid.
